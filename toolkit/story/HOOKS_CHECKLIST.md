# Hooks checklist (Sam, 13 Nov 2026: "From a psychological standpoint, what can we do in our script to make the viewers more hooked?" -> "Sure that would work.")

Run on every script draft before lock. A separate reviewer agent (has not seen the research) scores the draft against this list and returns PASS / FIX per item with the line ids and exact rewrites. Every hook sits on a fact that stays true: no fake cliffhangers, invented urgency or claims stronger than the evidence.

1. **One sharp question per chapter** (curiosity gap, Loewenstein 1994). A precise question, asked early in the chapter, answered late; the viewer can guess along. Mark it `hook: "question"` on the line. Model: "How long would those four companies take to spend that much? A year? A month?"
2. **2-3 open loops planted in the first minute**, each closed by name, spread (one mid-video, one at the end). Model: the 72 minutes (opening -> ch3 -> ch5 -> ch7). Note: the Zeigarnik memory claim does not replicate; what holds is the pull to resume something left unfinished, so a loop must feel deliberately unfinished ("Remember that.", "Hold that thought."), not just mentioned.
3. **A named person, place and problem in each chapter's first 10 seconds**, and the stakes said out loud once per chapter (what is lost if this fails) (narrative transportation, Green & Brock 2000).
4. **"But / therefore" joins, never "and then"** (South Park rule, styles/SOUTH_PARK_STUDY.md). The reviewer lists each chapter's spine as beats joined by but/therefore and flags every "and then".
5. **A reversal every 30-45 seconds** (prediction error): a setup that implies one outcome, then the opposite. Model: "The first modern search for alien signals, and what did we find? A plane."
6. **One "you" beat per chapter**: a guess, a "picture this", a "pause and count", a dare or invitation. Model: "give it seventy-two seconds".
7. **Concrete over abstract** in every key line: an object you could paint ("a borrowed amplifier", "a bake sale"), not "a small budget".
8. **One spoken running line that escalates**, with a twist on the last return. Model: "And the universe said... nothing." (x4, "Again." on the last).
9. **Energy map**: mark each chapter fast or slow in the outline; never two of the same side by side; a sincere beat before each big comic stretch.
10. **Peak and end** (peak-end rule, Kahneman): one marked peak (biggest reveal or laugh) at about 60-70%, and a last 30 s that lands emotionally (the keeper, section 4 of the research-story skill).
11. **Promise and payoff in the first 30-50 s**: restate the title's promise, preview the reward without the answer, one-line roadmap.

Scoring: the reviewer returns a table (item, PASS/FIX, line ids, fix). Fix every FIX or justify it in the script review file; Sam sees the table with the script.
